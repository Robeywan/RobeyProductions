Install Robey Productions

Open the history collection from your home screen or apps menu.

Robey Productions is installed.

iPhone or iPad
In Safari, tap Share and choose Add to Home Screen. Turn on Open as Web App if it appears, then tap Add.
Android
In Chrome, open the browser menu and choose Install and create shortcut or Add to Home screen, then select Install.
Chrome or Edge on a computer
Select the install icon in the address bar or look for the install option in the browser menu.
Safari on a Mac
From the menu bar, choose File → Add to Dock, then click Add.
