# Robey Productions

A static public hub for history study guides. The site uses plain HTML, inline CSS, and local image assets; no build step is required.

## GitHub Pages

Deploy from the `main` branch with the repository root (`/`) as the publishing folder. Keep `index.html`, `assets/`, `CNAME`, and `.nojekyll` at that root. The custom domain is `robeyproductions.org`; its DNS must point to the GitHub Pages host.

## Editing

Edit `index.html` to change page content, links, layout, and inline styles. Add or replace optimized images in `assets/` and update their relative paths in the HTML/CSS. Preserve accessible labels and descriptions.

## Image provenance

The page image credits identify the archival images and their source collections. Detailed metadata is in `assets/image-sources.json`; generated decorative background provenance is in `assets/generated-backgrounds.json`. Keep those records and the visible credits current when changing images.
